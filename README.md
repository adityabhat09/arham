## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose



## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /clients | Get clients |
| GET | /trades | Get trades |
| GET | /employees | Get employees |
| GET | /mappings | Get employee-client mappings |

## Features

- Clients
- Trades with filters
- My Clients
- Employees
- Incentives
- Stale-while-revalidate cache
- Retry mechanism
- Background refresh
